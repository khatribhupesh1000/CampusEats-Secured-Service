5. Security Checklist & Status Code Architecture

Status Code Meaning CampusEats Guard & Condition
200 OK Success Valid token presented, authorized role, request succeeded.
201 Created Resource Created Dish added by restaurant/admin, or order successfully placed.
401 Unauthorized "Who are you?" Missing or tampered Bearer token in header, or invalid password on /login.
403 Forbidden "I know you, but no" Customer trying to POST /items (RBAC), or Customer trying to view someone else's order (IDOR).
422 Unprocessable Validation Error Missing required dish name or invalid payload parameters.
